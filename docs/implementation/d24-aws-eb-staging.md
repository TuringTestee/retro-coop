## Deployment shape

1. Build the existing versioned client and coordinator Docker targets from one clean main commit. Publish both immutable image digests to a dedicated ECR repository. Record the source commit, image digests, client asset manifest and emulator hash together. The Elastic Beanstalk Docker Compose source bundle references exact digests, not mutable tags. Keep one coordinator instance: its rooms and temporary host ROMs live in memory/local disk and must not be split across instances.
2. Create a load-balanced Docker-on-AL2023 Elastic Beanstalk environment with one `t3.small` instance, fixed min/max capacity of one, a 443 HTTPS Application Load Balancer listener, and an ACM certificate for `retro-coop.1001.page`. Route 53 aliases the website hostname to the load balancer. Allow public HTTPS 443 and redirect HTTP 80 to HTTPS. Browsers and invited players can open the site without an IP allowlist. Set the default target process to the edge's HTTP port `8080` and health check `/healthz`; the instance security group accepts that port only from the ALB. AWS documents [Docker Compose support](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/docker-platform.html), [Compose's container-owned proxy](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/create_deploy_docker.container.console.html), [ACM HTTPS termination](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/configuring-https-elb.html), and [ALB listener and process settings](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/environments-cfg-alb.html).
3. Run the existing Nginx edge and Node coordinator on the same instance with Docker Compose host networking and its proxy setting `none`. The edge serves immutable client files, same-origin WebSocket `/coordinator/ws`, and authorized `/coordinator/rooms/*/rom` upload/download on HTTP `8080` behind the HTTPS ALB. Bind the coordinator to `127.0.0.1:8787`; do not publish its port. Verify host networking, the loopback boundary and the ALB process-port mapping locally and on the EB instance before declaring this shape accepted; if the platform cannot preserve them, revise this plan and review it before deployment.
4. ALB appends the transport client address to `X-Forwarded-For`; incoming client-supplied entries must not become the admission identity. Allow the edge port only from the ALB security group, make Nginx select the final ALB-appended address, and overwrite the forwarded header to the loopback coordinator with exactly that address. Keep `COORDINATOR_TRUSTED_PROXIES=127.0.0.1` and prove forged headers, IPv4/IPv6 and distinct clients. The original [proxy boundary](d24-proxy.md) remains the security contract.
5. Set `COORDINATOR_STAGE=staging`, exact `COORDINATOR_ORIGINS=https://retro-coop.1001.page`, the two included empty offers, required custom ROM upload, a bounded temporary ROM directory, and content-free logs. Uploads remain temporary while a room exists. Store the TURN secret in an AWS managed secret, scoped to the EB instance and relay, never in images, source, command output or browser variables.
6. Run coturn on a dedicated `t3.micro` EC2 instance with a stable public IPv4 address, UDP 3478 and a small relay port range open to internet peers. Use SSM without a public SSH rule, require time-limited credentials derived from the shared secret, cap allocation count and outbound relay bandwidth, and terminate it alongside the EB environment when the website is intentionally shut down. The HTTPS ALB cannot carry TURN's UDP allocations. Prove direct and forced-relay play; Relay only must fail visibly if TURN is unavailable instead of falling back to direct.

## Monthly cost and operating limits

[Elastic Beanstalk has no extra service fee](https://aws.amazon.com/elasticbeanstalk/pricing/); EC2, ALB, public IPv4, storage and transfer are billed. A current AWS Pricing API lookup on 2026-09-24 returned `t3.small` $0.0208/hour and `t3.micro` $0.0104/hour in `us-east-1`. The [ALB list price](https://aws.amazon.com/elasticloadbalancing/pricing/) is $0.0225/hour plus $0.008 per LCU-hour; [public IPv4](https://aws.amazon.com/vpc/pricing/) is $0.005/address-hour. At 744 hours, one EB `t3.small` is about $15.48, one relay `t3.micro` $7.74, ALB base $16.74, and an illustrative four IPv4 addresses $14.88: $54.84 fixed before EBS, LCU use, logs and transfer. Add 28 GiB of gp3 EBS at about $2.24/month and one continuous ALB LCU at about $5.95/month for a $63.03 baseline. The existing Route 53 zone adds no new zone fee for one alias. Internet egress is variable; model it at the published list rate without assuming credits or the shared free tier. Recheck actual address count, volume sizes and rates before provisioning.

Before provisioning, record a 31-day scenario including ALB, EC2, EBS, public IPv4, ECR/S3, logs, DNS and egress against the user-approved $50 actual-spend warning and $100 forecast shutdown trigger. Enforce the app's room/connection limits, edge response rate and global connection bound, a total upload request/size limit, and TURN allocations and bandwidth. Create monthly AWS billing alerts at $50 actual and $100 forecast spend and verify delivery to the operator. Check current and forecast spend daily. If the forecast reaches $100, stop new admissions and shut down the EB environment and TURN relay using the tested runbook. AWS reporting delay and publicly billed traffic mean this is not a hard cap; record the accepted residual risk and actual charges plainly. Do not announce a public beta until D21/D22 validation is complete.

## Decision if the first package cannot be deployed

Do not silently substitute a single-instance HTTP environment, a shared coordinator behind multiple instances, untrusted forwarding headers, or a relay-free public claim. Revise the exact affected architecture and review it before provisioning.
