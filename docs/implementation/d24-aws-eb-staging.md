## Deployment shape

1. Build the existing versioned client and coordinator Docker targets from one clean main commit. Publish both immutable image digests to a dedicated ECR repository. Record the source commit, image digests, client asset manifest and emulator hash together. The Elastic Beanstalk Docker Compose source bundle references exact digests, not mutable tags. Keep one coordinator instance: its rooms and temporary host ROMs live in memory/local disk and must not be split across instances.
2. Create a load-balanced Docker-on-AL2023 Elastic Beanstalk environment with one `t3.small` instance, fixed min/max capacity of one, a 443 HTTPS Application Load Balancer listener, and an ACM certificate for `retro-coop-stage.1001.page`. Route 53 aliases the staging hostname to the load balancer. Close HTTP 80; allow HTTPS 443 from only two named tester `/32` source addresses. Browsers reach only HTTPS. Record the CIDRs privately, and fail deployment if either is missing or not a public IPv4 `/32`. Configure the ALB target health check at `/healthz`. AWS documents [Docker Compose support](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/docker-platform.html), [ACM HTTPS termination](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/configuring-https-elb.html), and [ALB listener and process settings](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/environments-cfg-alb.html).
3. Run the existing Nginx edge and Node coordinator on the same instance. The edge serves immutable client files, same-origin WebSocket `/coordinator/ws`, and authorized `/coordinator/rooms/*/rom` upload/download. Bind the coordinator to loopback; do not publish its port. Make the ALB reach the edge's explicit instance port through the EB security group. Verify the selected Docker Compose networking and EB process-port mapping locally and in staging before declaring this shape accepted; if the platform cannot preserve the loopback boundary, revise this plan and review it before deployment.
4. ALB appends the transport client address to `X-Forwarded-For`; incoming client-supplied entries must not become the admission identity. Allow the edge port only from the ALB security group, make Nginx select the final ALB-appended address, and overwrite the forwarded header to the loopback coordinator with exactly that address. Keep `COORDINATOR_TRUSTED_PROXIES=127.0.0.1` and prove forged headers, IPv4/IPv6 and distinct clients. The original [proxy boundary](d24-proxy.md) remains the security contract.
5. Set `COORDINATOR_STAGE=staging`, exact `COORDINATOR_ORIGINS=https://retro-coop-stage.1001.page`, the two included empty offers, required custom ROM upload, a bounded temporary ROM directory, and content-free logs. Uploads remain temporary while a room exists. Store the TURN secret in an AWS managed secret, scoped to the staging instance and relay, never in images, source, command output or browser variables.
6. Run coturn on a dedicated short-lived `t3.micro` EC2 instance with a public IPv4 address, UDP 3478 and a small relay port range. Allow TURN traffic from exactly the same two tester `/32` addresses; use SSM without a public SSH rule, require time-limited credentials derived from the shared secret, cap allocation count and outbound relay bandwidth, and terminate the instance with the staging environment. The HTTPS ALB cannot carry TURN's UDP allocations. Prove direct and forced-relay play; Relay only must fail visibly if TURN is unavailable instead of falling back to direct.

## Cost and lifetime gate

[Elastic Beanstalk has no extra service fee](https://aws.amazon.com/elasticbeanstalk/pricing/); EC2, ALB, public IPv4, storage and transfer are billed. A current AWS Pricing API lookup on 2026-09-24 returned `t3.small` $0.0208/hour and `t3.micro` $0.0104/hour in `us-east-1`. At six hours these two instances cost about $0.19 before EBS and traffic. The [ALB list price](https://aws.amazon.com/elasticloadbalancing/pricing/) is $0.0225/hour plus $0.008 per LCU-hour; [public IPv4](https://aws.amazon.com/vpc/pricing/) is $0.005/address-hour. Model two ALB addresses, the EB instance address and the relay address: about $0.12 for four IPv4 addresses over six hours. A 31-day mistake costs roughly $15.48 for EB compute, $7.74 for relay compute, $16.74 ALB base, and $14.88 for four IPv4 addresses, or $54.84 before EBS, LCU use, logs and transfer. Recheck actual address count and rates at provisioning. Do not assume credits.

Before provisioning, record a six-hour and 31-day mistake scenario including ALB, EC2, EBS, public IPv4, ECR/S3, logs, DNS and egress. Enforce the app's room/connection limits, edge response rate and global connection bound, a total upload request/size limit, TURN allocations and bandwidth, and a six-hour environment/relay termination schedule. Create a $50 warning and $100 alert if the account permits. Billing alerts are monitoring, not a hard spend cap; public inbound requests are restricted by the two tester CIDRs, but traffic from either allowed network and malicious traffic still retain residual billing risk. The earlier GKE-specific residual-risk approval does not authorize a different AWS exposure beyond these bounds. Stop and tear down if the updated worksheet reaches the $100 ceiling or the network exposure differs from this plan. Do not call the staging URL a public launch.
