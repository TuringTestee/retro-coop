A person can host or join from the directory, prepare a game in the same lobby, and play without leaving the shared screen. Each path below includes its recovery route.

# Unified lobbies: journeys

| Journey | Forward path | Recovery |
| --- | --- | --- |
| Find and join | The directory opens with Host a new game at row zero. Search and count sit together. Click an available lobby row; enter a password only if that lobby requires one; land in its fixed player/game/menu layout. | A disabled row states why it cannot be joined. A wrong password stays beside the password field for retry. Service loss leaves the directory usable with Retry. |
| Host and invite | Click Host a new game; a public lobby with generated name opens. Click the name value to rename it in a centered dialog. Use Set Password beside the lobby name if needed. Copy invite beside the lobby name. | Rename or access failures preserve the current lobby and show a retryable reason. Copy failure opens a centered selectable link; closing it returns to the unchanged settings column. |
| Select and prepare | The host chooses Load NES game in the center game frame. A selected game's name and preview replace that cue. Change game follows the [cartridge replacement journey](gameplay-controls.md#change-the-cartridge-for-the-same-group), including during play. Each occupied controller owner uses the single centered Prepare action over the preview. | Loading failure keeps the lobby open with Retry or a new selection. A changed game revokes stale readiness. A battery restore does not block a preview; if preview generation fails but leaves the emulator unchanged, the game remains playable without one. Unprepared people remain named in their fixed rows; the host waits or kicks. |
| Start alone or together | Once all occupied controller owners are Ready, the host uses the single centered Start specified by [gameplay controls](gameplay-controls.md#direction). One countdown is broadcast; the game begins in the center, unmuted, with slots, game menu, chat and footer in place. | A changed membership, missing connection, or cancelled Ready prevents Start and gives the relevant person a next action. A failed start returns to preparation in the same lobby. |
| Join live play | A new person clicks a live lobby row. The matching game loads; the person enters the first open place. An active spectator can watch; a new controller owner presses Prepare to play, receives the current game state, then play resumes together. | The current game continues while a spectator prepares. A failed controller sync pauses at a completed frame and can be retried without relying on a departed player. |
| Manage people | The host clicks a whole slot row, then chooses a direct move/swap, Close/Open, or Kick. A departure compacts remaining people upward. | Stale revisions leave roles unchanged and explain retry. Kick asks for confirmation in a centered blocker. A failed kick leaves the person in place. |
| Change menu or enlarge game | Select Controls or Audio in the fixed right menu. Controls shows every actual mapping as an editable key button and the supported game actions; Audio owns sound and voice. See [gameplay controls](gameplay-controls.md) for idle feedback, fullscreen Save, coordinated Load/Restart and capture dialogs. Voice starts in push-to-talk mode when a peer connects. Click the running game to fill the window; click again or press Escape to return to the same lobby. | Unavailable audio or voice has a local retry in its menu; text and game continue. Host Load directly coordinates restored progress for everyone without leaving the lobby or showing a quick-save/acceptance menu; local Load is direct too. Save/Load progress and failure stay at the game’s top right. Invalid data or failed coordination keeps current progress recoverable. Fullscreen exit restores the fixed layout without ending play. |
| Switch theme | Use the top-right control to switch light or dark. The choice persists; without one, local time chooses light from 09:00 through 16:59. | Either theme keeps the same fixed layout and readable player/menu surfaces, including at 320 CSS pixels. |
| Leave | Click RETRO COOP or Back to Main Page, confirm in the centered dialog, end lobby/game/media, then show the directory. | Cancel keeps the live context. A failed leave keeps the lobby visible with a retryable message. |
